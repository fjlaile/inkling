Privacy Policy

Last updated: November 9, 2026

This policy covers Inkling Uploader, a command-line tool operated by JIA DONG (the owner of the YouTube channel Inkling). The tool has a single user: the channel owner.

Use of YouTube API Services

Inkling Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy (https://policies.google.com/privacy).

What data we access, and why

With the user's permission, given through Google's OAuth consent screen (scope "Manage your YouTube account"), the tool accesses the authorised user's own YouTube channel in order to: identify the channel (channels.list), upload videos (videos.insert), update video title, description, tags, privacy and scheduled publish time (videos.update), check upload and processing status (videos.list), set thumbnails (thumbnails.set), and add videos to the user's own playlists (playlists.list, playlistItems.insert). It does not access any other channel's or any viewer's data.

How data is stored and shared

The only data stored is the OAuth access and refresh token, kept in a file readable only by the owner on the owner's own computer. No YouTube API data is stored, sold or shared with any third party. The tool has no server, database, analytics, cookies or advertising. Data sent to Google is sent only to Google's own API endpoints over HTTPS.

How to revoke access and delete data

You can revoke Inkling Uploader's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. Revoking access invalidates the stored token; deleting the local token file removes all data the tool holds. On request we delete any stored data within 7 days.
